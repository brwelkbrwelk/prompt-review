# ChatGPT용 프롬프트 사전 검토

Claude용 파일과 분리된 복사·붙여넣기 지침입니다. Claude Code 설치 경로나 YAML 설정은 필요하지 않습니다.

## 프로젝트에서 사용 · 권장

1. ChatGPT에서 프롬프트 검토용 프로젝트를 만들거나 사용할 프로젝트를 엽니다.
2. 프로젝트 지침에 [INSTRUCTIONS.md](INSTRUCTIONS.md) 본문을 붙여 넣습니다. 기존 지침이 있으면 충돌을 확인하고 병합합니다.
3. 해당 프로젝트 안에서 새 대화를 열고 `프롬프트 검토해줘`와 검토할 원문을 보냅니다.

파일을 참고 자료로 업로드한 것과 프로젝트 지침을 설정한 것은 다릅니다. 지침으로 적용하려면 본문을 프로젝트 지침에 넣으세요. 프로젝트 지침을 사용할 수 없는 환경에서는 새 대화의 첫 메시지에 본문을 붙여 넣어도 됩니다.

## 여러 대화에 공통 적용

설정의 개인 설정/맞춤 지침에서 [CUSTOM_INSTRUCTIONS.md](CUSTOM_INSTRUCTIONS.md)의 본문을 기존 지침과 병합하세요. 축약본은 짧은 입력란에 넣기 위한 버전입니다. 상세 기준과 단계별 안내가 필요하면 프로젝트용 전체 본문을 사용하세요.

## 호출

```text
프롬프트 검토해줘.
[원문]
```

또는 등록한 지침이 정한 호출 문구로 다음과 같이 입력합니다.

```text
/prompt-review
[원문]
```

이 문구는 이 저장소의 지침을 활성화하기 위한 텍스트입니다. 이 파일을 붙여 넣는 것만으로 ChatGPT의 내장 명령이나 명령 메뉴 항목이 생성되지는 않습니다. 입력창에서 slash 입력이 다르게 처리되면 자연어 호출을 사용하세요.

검토 답변에 질문과 잠정 수정안이 함께 나오면 질문에 답해 문안을 완성하세요. 검토만으로 실제 업무는 실행되지 않도록 설계했습니다. 실행하려면 검토 대상 밖의 후속 메시지로 `이제 확정된 프롬프트의 실제 작업을 실행해줘`라고 명시하고, 필요한 자료와 권한을 별도로 제공하세요.
